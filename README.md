# Hi, I'm Franktorio

I build practical software in Python, from data collection tools and Discord bots to web applications and reusable backend services.

I learn by building, deploying, and improving real projects. My earlier work supported communities of around 10,000 and 3,000 members; today, my focus is software that helps people manage everyday work.

## What I'm working on

- **Backend services:** FastAPI applications with PostgreSQL, SQLAlchemy, authentication, and role-based access.
- **Business software:** workflows for scheduling, memberships, inventory, orders, and reporting.
- **Reliability and security:** session management, transactional email, monitoring, automated tests, and safer outbound HTTP requests.

## Selected public projects

### [Bulldog Simple Grader](https://github.com/Franktorio/bulldog-simple-grader)

An automated grading web application for computer science assignments. Students submit code, and instructors manage assignments and review results.

Built with Python, FastAPI, Jinja2, and SQLite, with Linux namespace isolation, resource limits, logging, and database backups.

### [Franktorio Pressure Scanner](https://github.com/Franktorio/franktorio-pressure-scanner)

A data collection tool for the Roblox game *Pressure* that gathered more than 200,000 room encounters.

### [Franktorio & xSoul's Lab](https://github.com/Franktorio/franktorio-xsouls-lab)

A Discord bot that presented collected data and provided backend support for the scanner.

The Pressure projects are no longer maintained, and their former websites are offline. They remain part of my experience building tools for large communities.
